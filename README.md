# Pooja Rajput – Makeup Artist site (React + Vite)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in dist/

## Where to edit
- `src/data/gallery.js` – photos + categories (home ring/marquee AND /gallery page)
- `src/data/site.js`    – WhatsApp number, phone/email, services, prices, steps, testimonials, FAQ
- `src/styles/global.css` – all styles
- `public/images/` – put look1.jpg … look12.jpg, hero-poster.jpg here
- `public/main.mp4` – hero video

## Routes
`/` home · `/gallery` full gallery. Vercel: `vercel.json` already rewrites all paths to index.html.
